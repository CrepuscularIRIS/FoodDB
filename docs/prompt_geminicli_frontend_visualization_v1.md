# GeminiCli Prompt: ModeA 可视化与可解释性强化（v1）

你是“监管科技 + 图可视化 + 交互叙事”方向的资深前端架构师。目标不是做普通后台，而是做“老师/专家 3 分钟看懂方法闭环和工作量”的汇报级界面。

## 一、项目背景（必须理解）
系统是乳制品供应链异构图风险研判平台，核心链路是：
1. 风险预测（节点/边 7 类风险概率）
2. 智能抽检（风险收益 vs 成本的双目标）
3. 抽检反馈回写（阳性/阴性更新）
4. 风险传播（按小时展示 12h 预测传播与真实传播对照）

当前已有页面：`/modela-v2`
当前已有数据与接口：
- `GET /api/modela/v2/view`
- `POST /api/modela/v2/modea_report`
- `POST /api/modela/v2/integrated_closed_loop`

## 二、你的输出目标
请输出一套“可直接交给工程实现”的前端增强方案，要求：
- 视觉上有“方法密度”和“结果可信度”
- 结构上让非技术专家也能看懂
- 交互上支持从“全局态势”钻取到“单节点决策依据”

## 三、硬性要求
### 1) 页面结构必须重构为四层
- 总览层：一句话结论 + 关键指标卡（命中率、Precision增益、预算效率、传播峰值）
- 机制层：风险预测、抽检策略、反馈更新、传播模拟四步流程可视化
- 证据层：节点/边贡献拆解、KQV权重、规则命中、不确定性来源
- 执行层：可导出清单（Top风险对象、抽检计划、复检建议）

### 2) 图表必须包含
- 异构图主图（节点/边风险同时编码）
- 反馈前后对比图（至少 2 个：排序增益 + 风险分层变化）
- 12h 传播对照图（预测 vs 真实）
- 抽检策略表（顺序、频次、成本、目标函数）

### 3) 可解释性必须落地
每个高风险节点点击后，必须展示：
- 综合分的组成（risk / credibility / uncertainty / priority）
- 7类风险概率条形图
- 邻域传播贡献（来自哪些边、贡献多大）
- 规则命中与证据质量（可追溯）

## 四、设计风格要求
- 风格关键词：监管中台、工业分析、可信审计
- 避免“花哨但空洞”
- 颜色语义固定：高风险红、预警橙、中风险黄、低风险青绿
- 字体/留白/对齐体现专业性，不要杂乱

## 五、工程约束
- 技术栈：React + Next.js + Tailwind + ECharts
- 在 1k+ 节点、10k+ 边下保持可交互（给出性能策略）
- 给出组件拆分清单（哪些组件可复用、哪些需要新建）

## 六、请你最终交付
1. 信息架构图（文字版）
2. 组件树与数据流（按接口字段说明）
3. 图表配置建议（ECharts option 级别）
4. 关键页面骨架代码（可直接放进 Next.js 页面）
5. 三阶段实施计划：
   - Phase1（1天可完成）
   - Phase2（3天可完成）
   - Phase3（1周可完成）

请务必输出“可执行方案”，不要泛泛而谈。
