# ModelA + RiskVisualization 整合思路（2026-04-06）

## 1. 目标
将两条链路统一到 ModeA：
1. 风险预测（节点/边 7类风险概率 + 风险等级）
2. 智能抽检（双目标优化：风险消除收益 vs 抽检成本）
3. 抽检反馈更新（阳性/阴性回写风险张量）
4. 传播联动（按小时预测未来链路与风险扩散，并与真实未来边做对照）

## 2. 输入数据
- 主输入：`dataset_3_24/enterprise_node.csv` + `graph_edges_reformatted_with_product.csv`
- 参考逻辑：`risk_visualization` 中的时序传播/抽检可视化机制

## 3. 工程落地
- 整合引擎：`scripts/modela_riskvis_integration.py`
- 后端接口：`POST /api/modela/v2/integrated_closed_loop`
- 前端页面：`frontend/app/modela-v2/page.tsx` 新增整合闭环区块

## 4. 核心机制
### 4.1 风险预测
- 使用现有 `modela_v2` 图数据 + `modea_formula_engine` 打分结果（risk/credibility/uncertainty/priority）。
- 节点与边分别输出 7维概率与综合分（排序主用）。

### 4.2 智能抽检优化（双目标）
- 目标函数：
  - 高风险优先
  - 单位成本收益优先
  - 不确定性（explore）作为次级加权
- 输出：抽检对象、顺序、频次、单位成本、目标函数值。

### 4.3 抽检反馈回写
- 对已抽检对象生成标签并回写：
  - 阳性：上调主风险维度
  - 阴性：按反馈强度下调
- 同步对邻接边/节点做局部联动更新。

### 4.4 传播与路径
- 从抽检阳性对象构造种子节点。
- 预测路径：基于抽检时刻之前历史边统计的转移偏好（近似链接预测）。
- 真实路径：抽检时刻之后真实未来边（窗口内）。
- 以小时为步长输出帧：活跃节点数、活跃边数、最大风险值。

## 5. 可解释输出
- 预测前 Top 风险节点/边
- 抽检策略详情
- 反馈命中率
- 反馈前后 Precision/Recall 增益
- 传播时序曲线（预测 vs 真实）
- 路径 Top 清单
- 抽检后风险张量（节点/边）

## 6. 当前边界
- 当前闭环中的“真实标签”是可控模拟（用于演示与流程验证）。
- 一旦接入真实抽检标签，可直接替换反馈标签生成逻辑。
