# 前端可视化增强 Prompt（可直接喂给设计/前端模型）

你是资深数据可视化设计师 + 前端架构师。请为“乳制品供应链风险研判系统（ModeA/ModeB）”输出一套可直接落地的高密度可视化方案。

## 业务目标
1. 让专家一眼看到方法链路：风险预测 -> 智能抽检 -> 反馈优化 -> 风险传播。
2. 突出“干货”：节点/边风险、Top5%热点、预算策略、传播路径、模型增益。
3. 页面风格要专业、工业级、可汇报，不是普通后台表格。

## 数据约束
- 异构图节点类型：原奶供应商、乳制品加工厂、冷链仓储中心、物流公司、零售终端。
- 风险维度：7类（非食用添加剂、农药兽药残留、食品添加剂、微生物、重金属、生物毒素、其他）。
- 需要同时支持全图与品类子图。

## 需要你输出
1. 信息架构（页面分区 + 用户视线顺序）
2. 图表矩阵（每个图的目标、字段、编码方式、交互）
3. 色彩系统（风险等级、节点类型、路径对比）
4. 动效规范（传播播放、抽检反馈前后对比动画）
5. 性能策略（大图分层渲染、阈值过滤、抽样）
6. 组件级实现建议（ECharts/Canvas/WebGL 取舍）
7. 最终给出 React + Tailwind + ECharts 的页面骨架代码（可运行）

## 强制要求
- 必须有“整合闭环总览区”：
  - 抽检命中率
  - 节点/边 Precision@K 增益
  - 传播预测 vs 真实曲线
- 必须有“策略执行区”：
  - 抽检顺序、频次、成本、目标函数
- 必须有“传播链路区”：
  - 预测路径 TopN 与真实路径 TopN 对照
- 必须有“风险张量区”：
  - 节点与边的 7维风险概率可查看

请给出最终可实施版本，不要空泛建议。
